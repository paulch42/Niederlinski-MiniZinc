# Niederlinski-MiniZinc

The book [A Gentle Guide to Constraint Logic Programming via ECLiPSe](https://www.cambridge.org/core/journals/theory-and-practice-of-logic-programming/article/abs/gentle-guide-to-constraint-logic-programming-via-eclipse-by-antoni-niederlinski-xiii-509-pages-published-by-jacek-skalmierski-computer-studio-third-edition-2014/0A4B221E17C621ECC64854C3D3B38D73) by Anton Niederlinski teaches constraint logic programming via the [ECLiPSe Constraint Programming System](https://eclipseclp.org). The book teaches through numerous exampes and contains copious exercises at the end of each chapter.

This repository provides solutions to many of the examples and exercises in the [MiniZinc](https://www.minizinc.org) constraint modelling language. MiniZinc is a higher level language than ECLiPSe, allowing more abstract and concise solutions to problems, which in some cases turn out to be rather simple. Indeed, comparing the MinZinc solutions to the ECLiPSe solutions amply demonstrates the benefits of MinZinc.

## Acknowledgement

All examples in this repository were sourced from Niederlinski's book. The book itself provides references to the source of some of the problems.
